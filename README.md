# Incremental Public Transport

Игрок развивает сеть общественного транспорта в процедурно сгенерированном городе. Жителям нужно добираться из одного района в другой. Условия победы включают общие для разных партий цели и одну или несколько местных задач, зависящих от районов, точек интереса и географии конкретной карты. С начала партии игрок видит подсказку о местной задаче. С появлением нужной точки интереса раскрываются направление поездок и критерий успеха. В демке для местной задачи достаточно одного успешного утреннего пика, в том числе при ручном выпуске автобуса. Расписание помогает поддерживать результат, пока игрок выполняет общие цели. Выполнив все цели, игрок может продолжить развивать этот город или засчитать победу и начать новую партию. В демке ориентир от запуска первого автобуса до возможности засчитать победу — около 20–30 минут. Длительность партии в полной игре решим позже. На текущем этапе сеть автобусная. Другие виды транспорта с собственными механиками отложены для дальнейшего развития. Удовольствие складывается из трёх связанных решений: куда провести линию, как наладить движение и куда вложить заработанное. Игрок сам переключается между видом города строго сверху и отдельной транспортной картой с линиями, остановками и пересадками. На схеме остановки остаются на своих местах, линия проходит через выбранный мост, а мелкие повороты сглаживаются. Вблизи пассажиры видны как точки у остановки. Их движение показывает очередь и посадку. Объём зданий передают форма крыш и тени. Вблизи вокзал, больница и университет различимы по простым силуэтам зданий. При отдалении их назначение показывает пиктограмма.

## Что входит в замысел

- На карте появляются точки интереса и остановки. На старте есть одно очевидное направление. Игрок сам соединяет две очевидные остановки, выпускает автобус и видит первую посадку. С первой выручкой появляется выбор между усилением этой линии и расширением сети. До запуска автобусов видны основные направления спроса между районами. У каждого направления есть базовый спрос с мягкими предсказуемыми пиками утром или вечером. Подробности открываются по мере работы линии. Точки интереса могут появляться самостоятельно и создавать спрос. Район растёт быстрее, когда увеличивается доля спроса, по которой пассажиры добрались до цели за приемлемое время. Для каждого направления ориентир равен времени кратчайшего пути по дорогам с запасом на ожидание и пересадки. Например, вокруг открывшегося университета может вырасти студенческий квартал.

- Игрок выбирает остановки по порядку. Игра предлагает путь между ними по улицам. Игрок может изменить участок пути, например выбрать другой мост. Игрок распределяет автобусы по линиям. Первые автобусы одной модели. По мере развития парка открываются модели разной вместимости и с разными расходами за время на линии. В демке сначала открывается вместительный автобус. Игрок вручную проверяет его на знакомой очереди, затем получает доступ к расписанию и планирует повторный выход. Вместительный автобус берёт больше пассажиров за рейс и обходится дороже за час на линии. Первые назначения игрок делает вручную. Когда парк достигает нужного размера, автоматически открывается первое расписание. В нём игрок планирует повторяющиеся выходы в часы пик. Игра показывает, какой интервал получается на каждой линии. Пассажиры сами находят путь с пересадкой на любой общей остановке двух линий. При долгом ожидании пассажир может уйти с остановки. Такая поездка остаётся незавершённой и не приносит оплаты. Если пассажиры регулярно уходят, у остановки на карте появляется значок. По нажатию игрок видит числа по направлениям.

- Сеть получает одну оплату, когда пассажир добирается до цели. Число пересадок на сумму не влияет. Выручку можно вложить в развитие сети. Каждый выпущенный автобус расходует деньги за время на линии, включая ожидание и пустые рейсы. Автобус в резерве расходов не создаёт. При отрицательном балансе автобусы продолжают ходить, расходы и выручка учитываются как обычно. Игрок может менять маршруты и перераспределять машины. Для покупки автобуса на счёте должна быть полная сумма. Общие цели демки — завершить заданное число пассажирских поездок и хотя бы один игровой день закончить с выручкой строго выше расходов на работу автобусов. Поездка с пересадками считается один раз по прибытии в пункт назначения. Покупки машин исключены из расчёта окупаемости дня.

## Открытые вопросы

- Предложение для проверки темпа: день 1 (0–8 мин) — первый рейс, выручка и выбор направления развития; день 2 (8–16 мин) — местная цель, ручная проверка вместительного автобуса и назначение следующего выхода; день 3 (16–24 мин) — автоматический выход, оценка очереди и возможность выполнить цели. Минуты — ориентир для настройки экономики. После первого пробного прохождения подобрать число завершённых поездок и долю своевременных поездок для местной задачи. Ориентир до возможности засчитать победу — 20–30 минут.

- Как перенести стиль Incremental Traffic в вид сверху? Предложенное направление — трёхмерный город из простых форм, минимум деталей, схематичные значки и транспорт. В папке проекта есть визуальные референсы.
